# Artificial Intelligence

Coursework and practical assignments completed for the **Artificial Intelligence (AI)** course, covering search algorithms, evolutionary computation, optimization, and predictive modelling.

## A1 – N-Queens Search Problem

The first assignment studies the **8-Queens / N-Queens problem** as an AI search problem. It explores **Breadth-First Search (BFS)**, **Depth-First Search (DFS)**, and **backtracking**, comparing their search behaviour, execution time, and time/space complexity. The report also discusses the use of a **Genetic Algorithm (GA)** as an alternative approach to the N-Queens problem.

## A2 – Genetic Algorithms and Optimization

Assignment 2 contains three practical tasks focused on genetic algorithms and optimization.

### Task 1 – Travelling Salesman Problem

Uses a **Genetic Algorithm** to search for an efficient route through a set of cities. The implementation represents candidate routes as populations and applies fitness evaluation, selection, crossover, and mutation to improve the route over generations.

### Task 2 – Function Optimization

Applies a **Genetic Algorithm** to optimize a mathematical fitness function involving three variables. The implementation generates a population of candidate values and repeatedly performs fitness evaluation, parent selection, crossover, and mutation.

### Task 3 – Rat Maze

Uses a **Genetic Algorithm** to search for a path through a maze. Candidate solutions represent movement sequences, while the fitness process evaluates progress toward the goal and applies penalties for invalid moves or collisions with maze walls.

## A3 – Regression and Neural Networks

Assignment 3 explores different approaches for modelling generated nonlinear data. It implements and compares **linear regression**, **second-degree polynomial regression**, and a **three-layer neural network**. The models are evaluated using **mean squared error (MSE)**, and prediction curves are visualized to compare how well the different approaches fit the data.
