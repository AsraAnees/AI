# Artificial Intelligence

Coursework and practical assignments completed for the **Artificial Intelligence (AI)** course, covering search algorithms, evolutionary computation, optimization, and predictive modelling.

## A1 – N-Queens Search Problem

The first assignment studies the **8-Queens / N-Queens problem** as an AI search problem. It explores **Breadth-First Search (BFS)**, **Depth-First Search (DFS)**, and **backtracking** for finding valid queen placements while avoiding conflicts.

The assignment compares the behaviour of the search approaches, including execution time and time/space complexity, and discusses how backtracking reduces unnecessary exploration. It also considers a **Genetic Algorithm (GA)** as an alternative search approach to the N-Queens problem.

## A2 – Genetic Algorithms and Optimization

Assignment 2 contains three practical tasks that apply genetic algorithms to different search and optimization problems.

### Task 1 – Travelling Salesman Problem

Uses a **Genetic Algorithm** to search for an efficient route through a set of cities. Candidate routes form the population, and fitness evaluation, selection, crossover, and mutation are used to improve solutions over successive generations.

### Task 2 – Function Optimization

Applies a **Genetic Algorithm** to optimize a mathematical fitness function involving three variables. Candidate values evolve through repeated fitness evaluation, parent selection, crossover, and mutation, demonstrating how evolutionary methods can search a numerical solution space.

### Task 3 – Rat Maze

Uses a **Genetic Algorithm** to search for a path through a maze. Candidate solutions represent movement sequences, while the fitness process rewards progress toward the goal and penalizes invalid movements or collisions with maze walls.

## A3 – Regression and Neural Networks

Assignment 3 compares different approaches for modelling generated nonlinear data: **linear regression**, **second-degree polynomial regression**, and a **three-layer neural network** with one hidden layer.

The dataset is divided into training and testing data, and the models are compared using **mean squared error (MSE)**. Prediction curves are also plotted to show how linear, polynomial, and neural-network approaches model the underlying data.
